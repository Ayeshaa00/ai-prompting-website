# 📚 PromptMaster AI

**Master AI Prompting with Ready-to-Use Examples!** 🎯

PromptMaster AI is a self-help style web app designed to **teach users how to craft effective AI prompts**. With a large library of categorized prompts, visual examples, and clear explanations, it’s perfect for **students, professionals, and AI enthusiasts**.

The app combines a **professional yet playful design** with an Indian context for examples, making learning practical, interactive, and enjoyable.

---

## ✨ Features

* ✅ **Learn the importance of good prompts**

* ✅ **Understand the structure of effective prompts**: Context, Task, Constraints

* ✅ **Explore top 5 LLM models (2025)** with direct links

* ✅ **Practice prompts across multiple AI tools**: ChatGPT, Gemini, Claude

* ✅ **Ready-to-use, categorized prompt samples** covering:

  * Travel Planning 🗺️
  * Study & Productivity 📖
  * Career Counseling & Motivation 💼
  * Food & Diet Planning 🥗
  * Health & Fitness 💪
  * Creative Storytelling ✍️
  * Business Ideas 💡
  * Job Search & Interview Prep 📝
  * Creativity (Image & Video Creation) 🎬
  * STEM & Tech Learning 🖥️
  * Critical Thinking & Debates 🧐
  * Data Analysis & Interpretation 📊

* ✅ **Interactive UI**: Sticky nav, hero section, comparison cards, accordion prompt sections

* ✅ **Visual cues**: Bad prompts = 🗑️ Trash | Good prompts = 🏆 Gold

## 📝 How It Works

1. **Importance of Good Prompts**: Understand why vague prompts lead to poor responses 🗑️ and well-structured prompts give “gold” quality answers 🏆.

2. **Structure of an Effective Prompt**:

   * **Context / Role**: Who AI should act as
   * **Task**: What AI should do
   * **Constraints / Style**: Length, tone, format

3. **Top 5 LLM Models (2025)**: Compare GPT-4o, Gemini 2.5 Pro, Claude 4, Grok-3, and LLaMA-based chat.

4. **Practice Prompts**: Copy, tweak, and test categorized prompts in **multiple AI tools** to see differences in outputs.

5. **Hands-on Learning**: Exercises encourage creativity, clarity, and continuous improvement.

## 🏁 Getting Started

### Prerequisites

* Node.js (v18+ recommended)
* npm

### Install & Run Locally

```bash
git clone https://github.com/Ayeshaa00/ai-prompting-website.git
cd ai-prompting-website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the app.

---

### Build & Deploy

```bash
npm run build
npm run deploy
```

> Deploys to GitHub Pages at:
> **[https://ayeshaa00.github.io/ai-prompting-website/](https://ayeshaa00.github.io/ai-prompting-website/)**

## 💡 Practice Tips

* Try prompts in at least **three AI tools** (ChatGPT, Gemini, Claude)
* Compare outputs & tweak prompts for better clarity and creativity
* Use context, tasks, and constraints to refine your instructions
* Play with examples to learn practical prompt engineering
